# Amma Labs

A blood-test booking web app: OTP login, test catalogue, cart, call / WhatsApp / online ordering, home collection slots, order tracking and online reports.

- `prototype/index.html` is the approved clickable UI. Open it in any browser.
- `CLAUDE.md` holds the project context and design rules. Claude Code reads it automatically.
- `docs/SPEC.md` covers features, data model, API, integrations and build order.

## Start in Claude Code

1. Unzip this folder, then run `git init` inside it (or push it to a GitHub repo if you're using Claude Code on the web).
2. Open the folder in Claude Code and paste this as your first message:

> Read CLAUDE.md, docs/SPEC.md and prototype/index.html. Then propose the stack and folder structure, ask me anything you need, and once I confirm, build step 1 of the build order in SPEC.md. Match the prototype's design exactly.
